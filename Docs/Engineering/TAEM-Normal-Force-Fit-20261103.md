# Forward-checked normal-force command seeds

TAEMNormalForceFitter turns a requested pair of wind-normal lift accelerations (vertical/rightward, m/s²) into an instantaneous command seed. It first projects into the relaxed configured lift/bank sector to obtain an inverse-lift suggestion, then forward-evaluates the real model at the allowed incidence boundaries, that inverse suggestion, the current incidence when in range, and any explicitly supplied additional incidences. No dense or synthetic capability grid is created.

For each sampled incidence, the fixed-magnitude lift vector uses the closest configured bank direction. Forward modeled lift and drag use the current Mach, q, sideslip, mass and device state. A sampled command with negative lift, nonfinite force or lift above the configured load limit is excluded; its force is never clamped down while retaining the same incidence. The positive-lift family does not cover negative-lift recoveries. Lower force-residual norm wins, with lower drag only for exactly equal force residual. This is seed construction, not the mission-outcome ranking.

The result retains requested force, relaxed projection, actual forward-modeled force, both residual components, modeled drag acceleration, selected target, evaluated incidence count, source epoch, explicit incidence coverage and immutable runtime model identity. The relaxed projection is never labeled the force produced merely because inverse lookup returned a target. Device requests remain inherited in the selected target; reported instantaneous force uses current device state, not instantaneous deployment of a newly requested device. Native continuation must re-evaluate actual actuator/device history and response.

The trim ceiling is a required caller input within configured limits. Passing a configured ceiling is not proof of empirical trim support. The result is only a sampled fit, not a global polar optimum or a complete attainable-command solution. Existing inverse/peak queries may be provisional or locally unsupported; historical model interpolation is not automatically empirical validation. Missing sampled admissible choices returns nil, not a physical-impossibility conclusion. No controller memory is initialized/reset here, and no model support/qualification/control ownership is granted.
