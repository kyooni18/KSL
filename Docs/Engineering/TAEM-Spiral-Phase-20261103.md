# Explicit spiral phase history and reprojection

SpiralPhaseHistory retains an unwrapped polar phase from an explicit initial winding hint. It separates observed polar motion from representation changes when spiral geometry is regenerated. The invariant is phase = initialPhase - measuredTurn + representationShift. No wrapped nearest-point choice alone establishes remaining winding.

Observation uses the current fixed spiral representation and measured point/epoch. Rebase requires the identical last observed point/epoch, available sampling coverage, and unchanged turn sense. It maps the new polar coordinate to the neighboring unwrapped branch and records the phase-coordinate shift separately. Changing center or radius at rest therefore changes representationShift, not measuredTurn. It cannot silently consume a new observation, change turn sense for free, or restore a lost history. Opposite-sense transitions still require an explicitly propagated and priced reversal.

Nonmonotonic/inconsistent same-time samples, gaps beyond explicit sampling coverage, exact half-turn ambiguity and undefined polar direction stop observation coverage. Initialization/rebase rejects unavailable coordinates. Near-center polar conditioning uses a relative sqrt(machine-epsilon) chart-coordinate guard, not a physical inner-HAC radius or turn-progress limit. Ordinary sampled-unwrapping aliasing beyond half a turn remains a limitation; adequate cadence must be independently established. No universal bank/turn-rate bound is invented.

This is coordinate history, not an assertion of physically tracked spiral progress. An off-reference path can change polar phase without performing the intended spiral. Actual course work, path-fit residuals, achieved forces, command history, winding intent and the complete recovery continuation must remain separate. Reprojection does not certify join-state continuity or attainability. The actual new trajectory must still be generated and priced from the measured seed.

One focused pure-geometric regression passed for both spiral senses. It crosses a wrapped branch with an explicit additional-turn history, shifts exit/center/radius at a fixed observed epoch, verifies measured work is unchanged and the invariant holds, advances measured phase under the new representation, round-trips serialization, and rejects free sense changes, hidden new epochs and coverage gaps. No plant, flight simulation or physical capability perturbation is involved. Log: `Validation/TAEM-Spiral-Phase-20261103/focused-test.txt`.

This helper is available for the new command path but has no production caller yet. It does not replace the live fitter or establish MM305 readiness.
