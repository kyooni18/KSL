Its terminal-plan builder receives the actually propagated prefix and continuation seed. It does not receive a fictitious tangent state. Exhausted, model-supported prefixes can receive a continuation; incomplete/unsupported prefixes remain recorded trials without invented terminal outcomes. No point-mass feasibility flag gates this continuation callback.

The caller supplies unique candidate IDs, topology intent, explicit command segments, and a nonnegative maximum evaluation count. The driver retains each trial, prefix, generated plan, outcome, incumbent link and comparison relation. Family exhaustion, candidate-budget truncation and cancellation are distinct endpoints. The diagnostic incumbent is the first terminal-evaluated alternative, replaced only by TerminalRecoveryOrder's challengerPreferred relation. An incomplete incumbent is not qualified or granted control. Unknown and incomparable alternatives remain in the result. All supplied candidates are examined within the explicit budget, without an early exit at the first qualified outcome.

No production caller or control owner is changed. Cancellation also reaches terminal propagation; existing trace-closure call sites still compile.
