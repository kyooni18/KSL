# Bounded coordinate shooting poll

`TAEMCommandSearch.refineOnce` performs one deterministic command-coordinate poll. It evaluates the supplied center and minus/plus neighbors in each segment's requested AoA, bank and duration. Each neighbor branches the identical original native seed and goes through the shared command/terminal propagation and comparison. No instantaneous bank/attitude or geometric join assignment is introduced.

Numerical step sizes are required explicitly in radians/radians/seconds. There are no tuned default gains, duration floors, scenario coordinates or fixed acquisition times. Alpha/bank proposals are projected to existing configured vehicle bounds; projected duplicates of the center are omitted. Nonpositive duration proposals and schedules beyond configured prediction-duration search coverage are skipped, not declared physically impossible. Other target/device requests and phase remain inherited. Derived commands discard stale tracking/admission/target-history diagnostics, since those describe the original request rather than the trial.

The supplied maximum evaluation count bounds propagated trials; exhaustion is reported as candidateBudget with the supplied stencil size, while familyExhausted means this one finite poll was evaluated. The driver retains all evaluated alternatives and uses the same partial recovery order. Unknown and incomparable results cannot claim an improvement. refineOnce remains one coordinate poll. The additional refine API repeats polls around the preferred incumbent, halves numerical mesh spacing after an unsuccessful poll, and stops at caller-specified positive resolutions or a single total evaluation budget. These resolutions describe command-parameter coverage, not flight tolerances or minimum maneuver duration. A fixed-family cache keyed by segment duration/alpha/bank avoids re-propagating identical schedules; phase/device requests remain fixed within this refinement. Unknown, invalid or incomparable evaluated alternatives make the resolution endpoint unassessed rather than a convergence claim. Missing original model support before any first-step propagation stops the loop as modelUnavailable, since all branches share that missing evidence. This is derivative-free local coordinate shooting, not a global optimum or a convergence proof. Physically generated topology seeds and reached-state spiral continuation remain to be implemented. Stencil construction is eager; its memory/runtime scaling has not been benchmarked for large segment counts. This API is not enabled in live control.
