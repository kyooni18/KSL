# Bounded coordinate shooting poll

`TAEMCommandSearch.refineOnce` performs one deterministic command-coordinate poll. It evaluates the supplied center and minus/plus neighbors in each segment's requested AoA, bank and duration. Each neighbor branches the identical original native seed and goes through the shared command/terminal propagation and comparison. No instantaneous bank/attitude or geometric join assignment is introduced.

Numerical step sizes are required explicitly in radians/radians/seconds. There are no tuned default gains, duration floors, scenario coordinates or fixed acquisition times. Alpha/bank proposals are projected to existing configured vehicle bounds; projected duplicates of the center are omitted. Nonpositive duration proposals and schedules beyond configured prediction-duration search coverage are skipped, not declared physically impossible. Other target/device requests and phase remain inherited. Derived commands discard stale tracking/admission/target-history diagnostics, since those describe the original request rather than the trial.

The supplied maximum evaluation count bounds propagated trials; exhaustion is reported as candidateBudget with the supplied stencil size, while familyExhausted means this one finite poll was evaluated. The driver retains all evaluated alternatives and uses the same partial recovery order. Unknown and incomparable results cannot claim an improvement. This is one coordinate poll, not an adaptive optimizer, convergence proof or a global topology search. Further polls, step adaptation, physically generated topology seeds and reached-state spiral continuation remain to be implemented. Stencil construction is eager; its memory/runtime scaling has not been benchmarked for large segment counts. This API is not enabled in live control.

Nine focused evidence, search and comparison tests passed. The added regression changes requested commands at configured attitude bounds on the genuine recorded STS state, without changing physical capability. It verifies clipped-neighbor omission, unique trial IDs, preserved device request, common origin, explicit unsupported-model outcomes and budget truncation. All these trials stop before model propagation because the original moment balance is missing; this is a search-contract check, not proof of useful turn response or improved landing performance. The rotational model's measured support remains short. Complete landing outcomes, full topology generation/refinement, regenerated spiral/winding/rebase continuity and live full-chain landing validation remain unproven. No flight or synthetic-capability campaign was run.
