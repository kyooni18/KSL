# Spatial reference from propagated commands

TAEMPropagatedReference provides a serializable spatial view of the native command prefix. It retains every propagated state in time order, the exact native join state, requested guidance, limited targets and issued controls as separate arrays. Commands[i] acts across states[i] to states[i+1]. The original comparison context, endpoint, completed segment count, final moment-support status and diagnostic remain attached. TAEMCommandTrial exposes this view through propagatedReference().

Runway chart position, tangent, radial height and local interval slope/curvature are derived from those propagated states. Crossrange is positive right; height is radial altitude above the actual selected runway elevation. Incoming curvature is sampled chart-course change divided by incoming chart displacement chord. Incoming slope is radial-height change divided by that chord. These are interval estimates, not continuous curvature or physical world arc length. Unknown/undefined/nonfinite quantities remain nil. chartCoverageComplete distinguishes a fully mapped prefix from gaps at chart singularities; a distance across missing chart geometry is not invented.

The comparison seed retains original measured inputs; the first propagated state includes the native plant's modeled atmosphere/force refresh. This view is modeled motion, not a claim about newly measured vehicle motion. Geometry is never independently assigned, and achieved alpha/bank are never substituted for future guidance targets. Replaying those achieved attitudes as fresh targets would change finite-response motion. Original requested/limited/issued histories remain inspectable.

This reference does not append an unpriced suffix, fit a geometric spiral, establish winding, or promote model support/qualification. An empty unsupported prefix has one state and no commands/curvature into a future segment. A course-complete prefix still needs its common terminal continuation. Serialization preserves evidence; decoded data requires validation before any future use for control. Existing production PathTrackingEngine/TerminalPlan and live MM305 ownership are unchanged.
