# Achieved-course command segment events

TAEMCommandSegment now optionally requests signed course work through untilCourseChange (radians, positive right). Its command is propagated until the sampled accumulated course change from that segment's actual start reaches the request. Segment duration is then a maximum local time-coverage budget, not an asserted maneuver duration. A nil event preserves existing timed-segment behavior. A zero or nonfinite event is rejected; an immediate direct continuation uses no command segments.

The event is evaluated from TAEMCourseProgress's fixed runway-chart motion diagnostic, independent of spiral center proposals. It is not spiral polar winding or proof of a spiral. The reached native state, command/controller/actuator memory and all accounting continue into the next segment. Reversal events measure signed change relative to their own actual start; neither body attitude nor progress is reset. This API is a primitive for motion-generated topology seeds; the seed generator and regenerated spiral remain unfinished.

Event completion occurs at a real control-step boundary. Overshoot is retained, rather than interpolating or teleporting to an ideal join. If local segment time ends before the requested course work, the prefix ends courseNotReached. Global duration/path coverage, unavailable sampled course, unsupported dynamics, cancellation and contact remain explicit endpoints. Contact reached on the last native step is reported as contact. Course coverage loss cannot qualify an event even if its last retained numeric progress appears favorable. Completed segment count is retained for partial multi-segment evaluation. Terminal continuation accepts only scheduleExhausted, so an unmet turn cannot obtain a fictitious terminal suffix.

Command refinement preserves the event while varying AoA, bank and time coverage. It does not optimize course-work targets yet. No new default angle, acquisition duration, force gain, radius gate or scenario branch is introduced. Requested course events can exceed a wrapped angle; realizing them still requires supported motion across all samples and an actual terminal continuation. Existing sampling-aliasing/model-support limitations remain.
