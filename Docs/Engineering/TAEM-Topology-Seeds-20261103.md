# Initial command topology seed family

TAEMTopologySeeds now generates a deterministic initial command family from explicit caller-supplied parameter knots (AoA, bank magnitude, signed-course-work magnitude and per-segment time coverage). It always retains supplied incumbent and protection schedules and adds an empty direct prefix. Each knot adds left/right course turns, left/right additional full-course-turn seeds, and left–right/right–left reversals. IDs identify each parameter/family trial distinctly. The caller then uses the shared native search/evaluation pipeline from one actual seed.

AoA and bank are requested together. Actual lift/drag/descent/attitude, control response, endpoints and any reachable terminal join are determined by propagation, not by independently allocated vertical/lateral force or a preselected geometric tangent. Finite bank/AoA inputs respect configured bounds; no new flight defaults, forces, timing, gain, radius gate or scenario coordinates are introduced. Devices and other target fields remain inherited from the supplied base target. The command phase is acquisition: a sustained command turn is not relabeled as an achieved spiral. Empty direct continuation does not assign runway alignment or reset the native controller.

The added 2π denotes an additional requested full course turn. It does not establish polar spiral winding. Reversal segments terminate on achieved course work relative to their own actual start and retain the finite roll-through-zero response. Topology parameters are explicit experimental search choices. This factory does not derive their values from a validated force/response envelope, independently generate optimized return-HAC or prolonged-turn parameters, establish attainable topology, or construct a regenerated spiral. Both senses remain available regardless of location; there is no five-kilometre or past-threshold prohibition.

A coverage error was found while connecting these families: refinement rejected a schedule whose sum of maximum segment durations exceeded the global prediction horizon. For course-event segments those durations are ceilings, not lower bounds on actual required flight time. The rejection is removed for both centers and neighbors. The native evaluator enforces the global horizon against actual propagated time, so a reversal may finish early or return explicit incomplete coverage. The factory likewise does not prune by summed ceilings. Evaluation budgets remain explicit in the search driver; this is not permission for an unbounded flight campaign.

The new regression verifies the nine emitted command candidates for one explicit knot, unique IDs, passed-through incumbent/protection requests, turn signs, additional full-course-turn request, reversal continuity intent, inherited devices and honest phase. A reversal whose two event ceilings exceed a one-tick global horizon still enters a one-evaluation refinement budget. Original missing moment evidence stops that trial before propagation. The search horizon is the only setting shortened; physical STS capability is unchanged. This is a command-contract check, not proof that a reversal or landing is attainable.
