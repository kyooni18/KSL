# STS entry diagnostics — 2026-10-09

These artifacts investigate live yaw-to-roll response and whether kRPC can produce an original-STS aerodynamic wrench grid without advancing the loaded vessel. They are diagnostic only. None supplies a shadow-gate pass, qualified aerodynamic cells, or landing evidence.

## Yaw pulse and inertia

[`live-yaw-inertia-analysis.json`](live-yaw-inertia-analysis.json), reproduced by [`analyze_sts_yaw_inertia.py`](../../../Tools/analyze_sts_yaw_inertia.py), recomputes body-rate slopes from the repeated vacuum yaw pulse and compares them with a pure body-yaw torque counterfactual using the measured full-vessel and root-part inertia tensors. Pitch and roll commands remained zero, and the bench recorded SAS/RCS off, zero dynamic pressure, and zero thrust. The retained probe converts KRPC angular rates to degrees/s before storing `body_rates`; the analysis preserves that unit and also reports rad/s² equivalents.

The positive pulse measured +0.0695°/s² roll and +0.1805°/s² yaw; the negative pulse measured −0.0678°/s² roll and −0.1763°/s² yaw. The roll/yaw acceleration ratio is about 0.385 for both polarities. Inverting the symmetrized full-vessel inertia tensor for a unit body-z torque predicts about 0.036; the root-part tensor predicts 0.059. The full-vessel result is about 10.7 times smaller than the observed ratio, so off-diagonal inertia alone does not explain the measured vacuum cross-axis response. This result does not isolate the actuator or control-frame cause, and it says nothing about atmospheric yaw/roll coordination.

## kRPC aerodynamic wrench grid

[`live-aerodynamic-wrench-grid.json`](live-aerodynamic-wrench-grid.json) evaluates 240 hypothetical states using `Flight.simulate_aerodynamic_wrench_at` on the loaded original STS. The grid varies Mach, angle of attack, sideslip, and bank while holding the directly measured live position and UT fixed. Each simulated velocity includes the body's rotational surface velocity so the requested Mach and air-relative angles match the intended values. The existing vessel, control surfaces, and action-group state supply the aerodynamic model; the probe issues no control or vessel-state setters.

At the captured state, the force and torque parity checks against live telemetry differed by 0.41% and 0.42%. The grid's achieved angle errors were below 0.00002 degrees. The live state remained paused and unchanged, and the named checkpoint hash remained `bb27c762add826731df3ad57332efd77d3d3a5d0928caa2ca361907ae0b1703f`.

This validates the API as a way to query counterfactual wrench values for the original vessel while preserving explicit input and checkpoint provenance. The retained grid is still only an upper-atmosphere slice at one position/UT (62.8 km, about 3.7–47.1 Pa). It is not a measured flight envelope or a lower-atmosphere certification set. A useful envelope needs additional altitude/UT slices and uncertainty checks against later live measurements; every simulated sample must remain labeled as unqualified diagnostic data.

[`shadow-witness-wrench.json`](shadow-witness-wrench.json) extends the grid to a hypothetical KSC Runway 09 location at the latest 38.0 km shadow trace point. The probe made 72 calls across four nominal Mach slices (4.0, 5.19, 5.212, 6.0), AoA 18°/28°, sideslip −5°/0°/+5°, and bank −40°/0°/+40°. It passed the trace UT explicitly and rotated the KSC position and local runway frame from the current paused UT using KSP's measured body angular velocity; the transformed position maps to KSC latitude −0.0486° and longitude −64.951° at the target epoch when viewed in the current frame. Requested AoA, sideslip, and bank were reproduced to floating-point precision.

At the matched shadow trace input (UT 10515.612, altitude 38,016.7 m, TAS 1,731.89 m/s, AoA 28°, sideslip 0° assumed, bank −40°), KSP's simulated static drag corresponds to 6.382 m/s² using the checkpoint-profile mass. The shadow model reports 5.379 m/s² and its reference is 9.950 m/s². This is a model discrepancy diagnostic only: the location is the runway center, the trace point is 4.55 km off center, sideslip is unrecorded and set to zero for the matched cell, dynamic pressure is scaled from the shadow trace, and the API uses zero angular velocity. It does not justify changing guidance or qualification thresholds.

The direct read-only probe verified one KSP process and the paused original STS at the named checkpoint (UT 9930.351826, mean altitude 71,972 m); SAS, direct controls, and throttle were off, thrust was zero, the configured speedbrake group was stowed, and all six control surfaces were neutral. RCS was enabled but idle. The paused loaded mass was 22,000 kg versus the checkpoint profile's 25,816.105 kg, so the profile mass was used for drag acceleration and the returned torque is descriptive only; it must not be used to infer angular acceleration or actuator coupling. The live state, control-surface state, checkpoint hash, and single-KSP-process invariant were unchanged.
