# Legacy CLanding

This directory preserves the previous flat `CLanding/` implementation after the modular tree became the canonical `CLanding/` source root.

Use `../CLanding` for normal development, builds, tests, launches, and validation. Treat `Legacy/CLanding` as historical reference unless a task explicitly asks for legacy archaeology or comparison.

`Validation/` under this directory likewise contains retired narrow tests and probes from the former architecture. They are reference material, not part of the current default regression gate.
